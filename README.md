# Zigma — копия сайта

Статическая копия публичных страниц https://zigma.by, снятая 2 ноября 2026 года.
Сохранены исходные HTML/CSS, шрифты, фотографии, адаптивная вёрстка, слайдеры и всплывающие окна.

## Запись отключена

Формы открываются, но данные никуда не отправляются и не сохраняются.
При нажатии «Записаться» показывается сообщение об отключённой записи.
Отправка блокируется обработчиками событий, запретом сетевых запросов и Content Security Policy.
Исходная аналитика отключена. Телефон и ссылки на мессенджеры сохранены.

## Страницы

Главная, о клинике, терапия, отбеливание, имплантация, костная пластика,
политика конфиденциальности четыре дополнительные страницы page51061xxx.html из основной карты сайта и шесть страниц публикаций /tpost/ из отдельных карт потоков Tilda. Всего 17 страниц.
Полный список — `scripts/page-inventory.json`, ресурсы — `scripts/asset-manifest.json`.

## Локальный запуск

```sh
python3 -m http.server 4173 --directory dist
```

Сайт доступен на http://localhost:4173. Для статического хостинга публикуйте каталог `dist`.

## Проверка и повторное копирование

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/mirror.py
.venv/bin/python scripts/verify.py
node --check dist/local-only.js
node scripts/verify-runtime.mjs
```

Скрипт копирования использует curl; исходные ответы кешируются в игнорируемом `.cache/`.
Карта не использует рекламный iframe Яндекса: Leaflet и его стили хранятся локально, а тайлы загружаются при показе карты; маршрут открывается в Яндекс Картах. Ленты, пагинация и всплывающие статьи читают локальные JSON-снимки из `dist/feeds/`. Внешние сервисы карты и ссылки на мессенджеры требуют интернета. Карта использует локальную библиотеку Leaflet 1.9.4 и OpenStreetMap с обязательной атрибуцией; загружается только при показе раздела. Маршрут ведёт к организации «Зигма» в Яндекс Картах (ID 146604389627). Кнопка «Построить маршрут» открывает маршрут к клинике в новой вкладке. Шаблон блока хранится в `scripts/map-block.html`; высота блока остаётся 385 px. Формы записи отключены независимо от карты.
Права на исходные материалы и фирменное оформление принадлежат их правообладателям.

Оптимизация: `scripts/prepare-site.py` удаляет подпись Tilda и повторно добавляющий её маркер, сжимает фотографии в WebP, исправляет отсутствующие окна и навигацию, отключает анимации появления при прокрутке и добавляет приоритетную загрузку первого экрана. Итоги — `scripts/optimization-report.json`. Leaflet лицензирован по BSD-2-Clause; текст лицензии — `dist/vendor/leaflet/LICENSE`.
