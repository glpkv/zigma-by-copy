# Zigma — копия сайта

Копия публичных страниц https://zigma.by, снятая 2 ноября 2026 года.
Сохранены исходные HTML/CSS, шрифты, фотографии, адаптивная вёрстка, слайдеры и всплывающие окна.

## Сбор заявок

Формы отправляют имя, белорусский телефон, путь страницы и согласие только серверному `/api/appointments`. Сервер сохраняет заявки в `appointments.csv` отдельного приватного репозитория `glpkv/zigma-appointments`. Это запрос обратного звонка, без автоматической записи в расписание клиники.
Ключ `APPOINTMENTS_GITHUB_TOKEN` хранится в секретах хостинга. Без ключа отправка отключена. Сервер проверяет приватность репозитория, формат номера и согласие, повторяет конфликтующие обновления и предотвращает дубли по ID заявки.
Исходная аналитика отключена. Телефон и ссылки на мессенджеры сохранены.

## Страницы

Главная, о клинике, терапия, отбеливание, имплантация, костная пластика,
политика конфиденциальности четыре дополнительные страницы page51061xxx.html из основной карты сайта и шесть страниц публикаций /tpost/ из отдельных карт потоков Tilda. Всего 17 страниц.
Полный список — `scripts/page-inventory.json`, ресурсы — `scripts/asset-manifest.json`.

## Локальный запуск

```sh
npm ci
npm run dev
```

Адрес локального сервера выводится при запуске. Исходные страницы и ресурсы — `public/`. Для публикации используйте сборку Sites/Vinext: `node <sites-plugin>/scripts/build-site.mjs`; результат — `dist/`.

## Проверка и повторное копирование

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/mirror.py
.venv/bin/python scripts/verify.py
node --check public/local-only.js
node scripts/verify-runtime.mjs
node scripts/verify-intake.mjs
```

Скрипт копирования использует curl; исходные ответы кешируются в игнорируемом `.cache/`.
Карта — официальный iframe-виджет Яндекса, привязанный к карточке стоматологии «Зигма» (`ol=biz`, `oid=146604389627`), а не к результату поиска адреса. Виджет загружается лениво при приближении к разделу контактов. Постоянная ссылка на карточку клиники доступна рядом с картой. Кнопка маршрута передаёт идентификатор организации и координаты отмеченного Яндексом входа: 53.88664961, 27.51818338. Источник — карточка организации https://yandex.by/maps/org/zigma/146604389627/, сверено 3 ноября 2026 года. Шаблон блока — `scripts/map-block.html`. Ленты, пагинация и всплывающие статьи читают локальные JSON-снимки из `public/feeds/`. Карта и мессенджеры требуют интернета. Внешние обработчики форм Tilda остаются отключены.
Права на исходные материалы и фирменное оформление принадлежат их правообладателям.

Тема автоматически следует `prefers-color-scheme`. В тёмной версии используется отдельная палитра текста, фонов, полей и кнопок; фотографии и карта не инвертируются. На экранах уже 960 px шапка и подвал используют обычный поток и flex/grid, включая телефон и три мессенджера. `scripts/finish-site.py` применяет эти изменения после копирования, обновляет шесть статей и удаляет технические заглушки. Источники и редакционные ограничения — `scripts/content-sources.md`.

Оптимизация: `scripts/prepare-site.py` удаляет подпись Tilda и повторно добавляющий её маркер, сжимает фотографии в WebP, исправляет отсутствующие окна и навигацию, отключает анимации появления при прокрутке и добавляет приоритетную загрузку первого экрана. Итоги — `scripts/optimization-report.json`. Leaflet лицензирован по BSD-2-Clause; текст лицензии — `public/vendor/leaflet/LICENSE`.

## Проверка интерактивных элементов

`public/interactions.js` исправляет внешние стрелки фотогалерей, добавляет кнопки,
клавиатурное управление и нативный горизонтальный скролл карточек, синхронизирует
видимость FAQ с `aria-expanded`, закрывает native dialog по Escape при активных
legacy-обработчиках Tilda и убирает вторую мобильную шапку.

Повторная браузерная проверка (без отправки заявок): запустите сервер, откройте
проверяемый адрес через `playwright-cli open`, затем выполните
`playwright-cli run-code "$(cat scripts/verify-interactions.js)"`.
Сценарий проверяет реальные клики и видимую фотографию, границы каруселей,
повторное сворачивание FAQ, меню, окна заявки и помощника на ширинах 390 и 1280 px.

Проверка движения фотолент: `playwright-cli run-code "$(cat scripts/verify-conveyor.js)"`
на открытом сайте. Проверяются фактическое смещение обеих лент под курсором,
мобильная и десктопная ширина, смена ширины и сохранение лент при изменении
только высоты окна. Размеры пересчитываются через ResizeObserver после изменения
геометрии исходных фотографий; наведение не останавливает движение.
